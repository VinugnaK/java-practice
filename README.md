## ▶️ Getting Started

### Clone the repository

```bash
git clone https://github.com/VinugnaK/Java-practicee.git
```

### Navigate to the project

```bash
cd Java-practicee
```

### Compile a Java file

```bash
javac FileName.java
```

### Run the program

```bash
java FileName
```
