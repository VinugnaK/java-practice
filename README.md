## ▶️ Getting Started

Clone the repository

```bash
git clone https://github.com/VinugnaK/java-practice.git
```

Navigate to the project

```bash
cd java-practice
```

Compile

```bash
javac FileName.java
```

Run

```bash
java FileName
```
